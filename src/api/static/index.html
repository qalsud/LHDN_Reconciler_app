🧾 LHDN Reconciler

Reconcile your General Ledger against LHDN MyInvois submissions. Four audit buckets, anomaly scores, AI narratives, one Excel pack.

API docs Open the web app

What it does

✅ Matched

TIN + reference agree, SST and totals within tolerance. No action.

⚠️ Unsubmitted sales

In the ledger, absent from MyInvois. Submit urgently.

🟡 SST mismatches

Counterpart found but tax differs. Recompute, credit/debit note.

🔴 Missing UUID

Submitted under a different reference, or LHDN-only. Link the UUID.

Use the API

curl http://localhost:8000/health

curl -X POST http://localhost:8000/api/v1/reconcile \
  -H "X-API-Key: <your-key>" \
  -F gl_file=@gl.csv -F lhdn_file=@lhdn.json

curl -H "X-API-Key: <your-key>" \
  http://localhost:8000/api/v1/runs/<run_id>/workbook -OJ

Operate it

🔑 Multi-tenant keys

Per-company API keys, SHA-256 hashed. Runs are isolated per tenant with a full event audit trail.

💾 Postgres + SQLite

SQLite file for local dev, Postgres in production. Same repository seam.

🤖 Hybrid AI

Deterministic Pandas matching; AI only maps schemas, reads PDFs and narrates variances.
